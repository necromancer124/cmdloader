# cmdloader notes

This fork turns DownRim into a broader Steam Workshop downloader helper with:

- AppID auto-detection for Workshop items.
- Clean/deduplicated Workshop input handling.
- Separate Steam login username guidance.
- Steam Guard / 2FA setup helper for SteamCMD.
- Selectable download directory.
- Downloaded item management/delete UI.
- Per-item live progress reporting.
- Ready Windows EXE package under `release/DownRim-ready/`.
